# MediAI Molecular Intelligence

> A transparent and reproducible cheminformatics project for molecular-property analysis, ADMET/QSAR benchmarking, and evidence-based compound prioritization.

## Mission

MediAI Molecular Intelligence is an open research and education project being built to explore how cheminformatics, machine learning, and pharmaceutical knowledge can support early-stage drug-discovery research.

The project focuses on scientifically responsible computational workflows. It does not claim to discover, validate, or approve medicines.

## Project Goals

- Analyze molecular structures using RDKit.
- Calculate physicochemical and drug-likeness properties.
- Build transparent baseline QSAR and ADMET prediction models.
- Compare classical machine-learning methods with molecular deep-learning models.
- Use realistic validation methods, including scaffold-based evaluation.
- Document datasets, assumptions, limitations, failures, and results clearly.
- Progress toward evidence-based compound prioritization for focused research problems.

## Day 01 Module

The first module will analyze known molecules using RDKit and calculate:

- Molecular weight
- LogP
- Hydrogen-bond donors and acceptors
- Topological polar surface area
- Rotatable bonds
- Lipinski Rule of Five flags

## Planned Roadmap

1. **Cheminformatics foundation** — molecular cleaning, descriptors, fingerprints, similarity, and drug-likeness analysis.
2. **Molecular ML baseline** — RDKit/Morgan fingerprints with transparent machine-learning models.
3. **Robust evaluation** — random vs scaffold split, error analysis, calibration, and model limitations.
4. **Advanced modelling** — graph neural networks and molecular foundation-model comparisons where justified.
5. **Focused research workflow** — evidence-based compound prioritization for a validated scientific problem.
6. **Research communication** — source-linked notebooks, reports, videos, and reproducible documentation.

## Research Use Disclaimer

This repository is intended only for education, computational research, and hypothesis generation.

Outputs from molecular-property analysis or machine-learning models do not establish drug efficacy, safety, clinical suitability, or regulatory approval. Any computational result requires appropriate scientific review and experimental validation.
